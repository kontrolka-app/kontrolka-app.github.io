# Контролька — задачи по UX и внешнему виду

Задание для Claude Code. Репозиторий: `kontrolka-app/kontrolka-app.github.io` (GitHub Pages, ванильный JS без сборки, ES-модули, `localStorage`).

Источник — разбор пути ученика (CJM) на десктопе 1366px и телефоне 390px. Макеты: холст «Контролька — CJM и редизайн» (главная при возвращении, список тем, страница темы).

## Как работать

- Сначала прочитай `README.md`, `js/app.js`, `js/state.js`, `js/screens/browse.js`, `js/screens/results.js`, `css/*.css`.
- Делай задачи **по одной**, в порядке приоритета. После каждой: `npm test`, `npm run validate`, ручная проверка через `npm start` на ширине 390px и 1366px. Один коммит на задачу.
- Ограничения:
  - без сборщиков, фреймворков и npm-зависимостей;
  - структуру `localStorage` менять только с миграцией в `js/storage.js`, старые данные пользователя не должны теряться;
  - сохранить доступность: skip-link, фокус на `.page-title`, `aria-*`, клавиатурная навигация, контраст текста ≥ 4.5:1, кнопки ≥ 44px;
  - сохранить тёмную тему и три размера текста из настроек;
  - данные заданий (`data/content/*.json`) не трогать.
- Тексты интерфейса — на «ты», коротко, для ученика 4 класса.
- Если задача требует решения, которого здесь нет, — спроси, не придумывай.

## Фаза 1 — баги и вход (высокий приоритет)

### 1.1 Баг: список тем без выбранного класса
`#/topics/math` при `settings.grade === null` показывает «null класс», «Всего тем: 0» и «По запросу «» ничего нет» (`topicsScreen` в `js/screens/browse.js`, ~стр. 206).
- Сделай как в `subjectsScreen`/`examScreen`: если класса нет — подставь единственный доступный класс (см. 1.2) или `navigate('grade')`.
- Пустое состояние поиска показывай только при непустом запросе.
- Проверь также `#/topic/<id>` и `#/exam/<id>` без класса.
- Добавь тест.

### 1.2 Автовыбор класса, когда он один
Сейчас 10 из 11 плиток в `gradeScreen` — «пока пусто», а «Начать подготовку», «Пробная контрольная» и «Выбрать класс» на главной ведут на этот экран.
- Если в контенте ровно один класс (`new Set(content.topics.map(t => t.grade))`), при первом входе выбери его автоматически и веди сразу на предметы. Сообщи об этом тостом «Выбран 4 класс — сменить можно в настройках».
- На экране выбора класса показывай только классы с заданиями. Пустые сверни в одну строку: «Скоро: 1–3, 5–11 класс».
- Когда классов с заданиями станет больше одного, поведение должно вернуться к обычному выбору (без правки кода).

### 1.3 Короткое знакомство при первом входе
- Первый запуск (нет истории и нет имени): экран из одного шага — «Как тебя зовут?» (необязательно, с кнопкой «Пропустить») + класс, если их больше одного. Затем — предметы.
- Имя уже хранится в настройках, используй существующее поле.

## Фаза 2 — страница темы и список тем (высокий приоритет)

### 2.1 Страница темы: главное действие наверху
Сейчас на телефоне «Начать» — внизу, после правила и пяти настроек (`topicScreen`, ~стр. 282).
- Порядок: заголовок → мини-статистика (последний результат, число ошибок к разбору, всего заданий) → **главная кнопка** → вторая кнопка → правило → настройки.
- Главная кнопка по ситуации: есть невыученные ошибки по теме → «Повторить N ошибок»; иначе → «Начать — 10 вопросов» (число из настроек по умолчанию).
- Правило (`theoryBlock`) — свёрнуто по умолчанию (`open: false`), заголовок «Вспомнить правило». На первом заходе в тему можно оставить открытым.
- Настройки тренировки спрятать в `<details>` «Ещё настройки: количество, сложность, порядок». Снаружи оставить только режим двумя кнопками: «С подсказками» / «Как на контрольной».
- Количество вопросов — только чипы (5 / 10 / 20 / Все), убрать дублирующее числовое поле.

### 2.2 Список тем: компактнее и со статусом
Сейчас на 390px лента ~6000px. Раздел повторяется дважды (заголовок КАПСОМ + та же строка в карточке), «4 класс» и сложность «средняя» почти везде одинаковые.
- Карточку темы заменить строкой: значок статуса + название + процент. Описание убрать из списка (оно есть на странице темы).
- Статус из истории: «не начата» (серый круг), «в процессе» (жёлтый круг + %), «освоена» (зелёная галочка, ≥ 80% в последней попытке). Пороги вынеси в константы.
- Убрать из строки повтор раздела, «4 класс» и индикатор сложности.
- Разделы — сворачиваемые (`<details>`), в заголовке «освоено X из Y». Раскрыт раздел с последней пройденной темой.
- Сверху блок «Стоит повторить»: темы с результатом < 70% (тот же порог, что в результатах).
- В шапке экрана: «Освоено X из N тем».
- При поиске раскрывать все разделы с совпадениями.

## Фаза 3 — главная при возвращении и результат (средний приоритет)

### 3.1 Главная: «Продолжить» вместо статичного героя
`homeScreen`, ~стр. 19.
- Если есть история: блок-герой «Привет, {имя}!» + карточка «Продолжить» с одной кнопкой. Логика выбора: последняя тема с ошибками → «Повторить N ошибок»; иначе следующая не начатая тема того же раздела → «Следующая тема».
- Убрать дубль: «Последний результат» и «Мой прогресс» сейчас показывают одно и то же. Оставь одну карточку прогресса (тренировок, средний %, освоено тем).
- Карточки предметов показывают «X из N тем» вместо «N тем · M вопросов».
- Нижние блоки: «Подготовка к ВПР» поднять сразу под предметы. «Олимпиадные задачи» — вторичным блоком. «Составь тест для класса» — скромной строкой-ссылкой, не плашкой.

### 3.2 Цель дня и серия дней
- В настройки: «Цель на день» (5 / 10 / 20 вопросов, по умолчанию 10).
- На главной: прогресс-бар «Сегодня X из Y вопросов» и бейдж «N дней подряд» (день засчитывается, если цель выполнена). Считать по датам сессий в истории, по локальному времени.
- Без штрафов и грустных сообщений за пропуск — серия просто начинается заново.

### 3.3 Экран результата: один следующий шаг
`resultScreen`, ~стр. 57.
- Одна главная кнопка по ситуации: < 70% → «Повторить ошибки (N)», ≥ 70% → «Следующая тема». «Пройти ещё раз», «На главную» и «Скопировать результат» — вторичными, в одну строку или меню.
- Если тема уже проходилась: строка «В прошлый раз 30% → сейчас 70% ↑».
- При ≥ 80%: «Тема освоена!» и короткая анимация (с учётом `prefers-reduced-motion`).

### 3.4 Тренировка: мелочи
- Enter = «Ответить», затем Enter = «Дальше» (если ещё нет).
- В режиме обучения таймер скрыт (время всё равно пишется в результат).
- Счётчик «3 подряд!» при серии верных ответов (с 3 и дальше).

### 3.5 «Нашёл ошибку в задании?»
Задания пока не проверены взрослым (`verified: false` у всех), и ученик может заметить неверный ответ или опечатку. Нужно, чтобы он мог сообщить об этом автору — Максиму.
- Где: небольшая текстовая кнопка «Нашёл ошибку?» под вопросом после ответа (в тренировке и в разборе ошибок на экране результата). Не мешает главной кнопке «Дальше».
- По нажатию — короткая форма: что не так (чипы «Неверный ответ», «Опечатка», «Непонятный вопрос», «Другое») + необязательное поле «Напиши, как правильно» (до 300 символов).
- В сообщение автоматически попадают: `id` вопроса, тема, текст вопроса, ответ ученика, ответ из данных. Имя ученика — только если он сам отметит «Подписаться».
- Ответ ученика **не пересчитывается** и результат не меняется — решение принимает Максим, правит данные сам.
- Отправленное сохраняется локально (поле в данных, добавить в `sanitizeData`), у вопроса появляется пометка «Ты уже сообщил об ошибке» — чтобы не слать дважды.
- Логика сборки сообщения — в модуле без DOM (например `js/reports.js`) с тестом.

**Доставка — решено (2026-10-29): кнопка «Скопировать сообщение».** Ученик сам пересылает текст Максиму в мессенджере. Без чужих сервисов и без адресов на сайте (сервера нет, см. «Не делать сейчас»). После копирования — тост «Скопировано! Отправь Максиму». Если буфер недоступен — показать текст в поле, чтобы выделить и скопировать вручную.
- Не делать: `mailto:` (адрес виден всем) и внешние формы (данные детей уходят в чужой сервис, 152-ФЗ).

Проверка: ответить на вопрос → «Нашёл ошибку?» → выбрать «Неверный ответ» → скопировать; в буфере текст с `id` вопроса и обоими ответами; у вопроса пометка «Ты уже сообщил».

## Фаза 4 — внешний вид (средний приоритет, после фаз 1–3)

Цель — теплее и «детскее», не теряя аккуратности. Ориентир — макеты на холсте.

### 4.1 Токены и шрифт
- Вынести цвета в CSS-переменные в `css/styles.css` (если ещё не вынесены), светлую и тёмную тему.
- Фон светлой темы: тёплый `#F7F5F0` вместо сине-лавандового, текст `#1B1F3B`, основной `#2F4FD8`.
- Шрифт: Nunito (Google Fonts, кириллица, веса 400/700/800/900) с фолбэком `system-ui`. Заголовки 800–900. Подключать через `<link>` в `index.html` с `display=swap`.
- Убрать градиент из героя главной.

### 4.2 Цвет предмета
- У каждого предмета свой цвет, задаётся в `data/subjects.json` полем (например `color`), а не в коде:
  - математика `#E3E9FF` / текст `#2440B8`;
  - русский `#FDE3DA` / `#9A2E12`;
  - окружающий мир `#DDF3E6` / `#17663A`;
  - чтение `#FFF0C7` / `#7A5300`.
- Цвет тянется по всему пути: карточка предмета → шапка списка тем → шапка страницы темы → полоса прогресса в тренировке.
- Проверь контраст обеих пар (фон/текст) в светлой и тёмной теме. Для тёмной подбери отдельные пары.

### 4.3 Один стиль иконок
- Сейчас эмодзи (📝🔢🌍📚🚀✏️📘🎯🏅) смешаны с линейными SVG-иконками меню. Замени эмодзи в интерфейсе на линейные SVG в стиле существующих (`icon()` в `js/ui.js`).
- Иконки предметов — тоже в `subjects.json` по имени иконки.

### 4.4 Нижнее меню на телефоне
- 5 пунктов → 4: «Главная», «Темы», «Прогресс» (сейчас «История»), «Я» (настройки + «Мои тесты»).
- «Мои тесты» остаются доступны с главной и из «Я».

## Фаза 5 (этап F) — геймификация (после фазы 3)

Берёт серию дней из 3.2. Логика — в новых модулях без DOM (`js/stats.js`, `js/achievements.js`) с тестами. Каждый шаг — отдельный коммит.

Принципы: без рейтинга класса (нужен сервер — см. «Не делать сейчас»), без штрафов и сгорающих очков, больше половины значков — за регулярность и исправление ошибок, а не за 100%. Соревнуются ребята «вживую»: показывают экран или присылают карточку (5.5).

### 5.1 Счётчики за всё время
- Поле `stats` в данных: дни с занятиями, лучшая серия дней, всего вопросов, верных ответов, освоено тем. Хранится отдельно от истории — история обрезается до `HISTORY_LIMIT`, счётчики нет.
- День засчитывается, если решён хотя бы один вопрос (просто открыть сайт — не считается). Даты по локальному времени.
- Если `stats` нет — заполнить из имеющейся истории, чтобы у тех, кто уже занимался, ничего не пропало.
- Добавить в `sanitizeData`; экспорт/импорт резервной копии — со счётчиками. `SCHEMA_VERSION` не поднимать: поле необязательное, старые копии должны импортироваться.
- Проверка: на экране «Я» видны цифры, после тренировки они растут.

### 5.2 Значки
Дата получения запоминается, значок не пропадает при обрезке истории.

| Значок | За что |
|---|---|
| Первый шаг | первая тренировка |
| Неделя | 7 дней подряд |
| Месяц занятий | 30 дней за всё время |
| Сотня / Пятисотка / Тысячник | 100 / 500 / 1000 вопросов |
| Отличник | тест на 100% (от 10 вопросов) |
| Снайпер | 10 верных подряд в одной тренировке |
| Работа над ошибками | повторил ошибки и исправил все |
| Рывок | тема: было меньше 50% → стало 80% и больше |
| Знаток раздела | освоены все темы одного раздела |
| Путешественник | занимался по всем предметам |
| Олимпиадник | верно решил олимпиадную задачу |
| Готов к ВПР | прошёл вариант ВПР |
| Учитель | составил свой тест для класса |

- Перед реализацией «Олимпиадника» и «Готов к ВПР» проверить, как такие задания помечены в данных; если пометки нет — предложить замену, данные не трогать.
- Иконки значков — линейные SVG в стиле `icon()` (см. 4.3), не эмодзи.

### 5.3 «Мои достижения» на экране «Я»
- Цифры из 5.1 и сетка значков. Неполученные — серые, с подсказкой, как получить.
- Новый значок — на экране результата, с короткой анимацией (с учётом `prefers-reduced-motion`).

### 5.4 «Удивлялки»
- Строки вида «ты решил больше вопросов, чем страниц в учебнике математики».
- Только с проверенными числами: сначала таблица «сравнение — число — источник» (например, страницы учебника из `uchebniki/`) на согласование, в код — только одобренное.

### 5.5 Карточка-хвастушка
- Кнопка «Поделиться достижениями» копирует текст: «{имя} в Контрольке: 23 дня, 640 вопросов, 9 значков из 15».
- Только текст; картинка — возможно позже, отдельной задачей.

### 5.6 Аватарки
- 10–12 своих смешных персонажей в SVG, в одном стиле с иконками (например: енот в очках, кактус-отличник, сонный кот, динозаврик с рюкзаком). Не копировать чужих персонажей.
- Выбор — в «Я»; аватарка видна на главной и в блоке «Мои достижения». В текстовой карточке (5.5) — имя персонажа.
- Часть аватарок и аксессуаров (шапка, шарф, очки, корона) открываются значками из 5.2, например «Неделя» → шарф, «Тысячник» → корона. Закрытые — серые, с подсказкой, каким значком открываются.
- Выбор хранится в `settings` (добавить в `sanitizeData`); неизвестный или ещё не открытый вариант → аватарка по умолчанию.

### 5.7 Компаньон
- Свой персонаж (не Скрепка и не другой чужой) в углу экрана с облачком текста. Состояния: обычный, радуется, думает. Картинки — отдельными SVG-файлами, чтобы потом легко заменить (например, на рисунок ребёнка).
- Говорит только заранее написанные фразы на события: начало дня (с целью дня), серия верных ответов, ошибка, новый значок, освоенная тема, возвращение после перерыва. Фразы — в отдельном файле; весь список сначала на согласование.
- Не подсказывает ответы (проверка только по данным вопроса), не перекрывает задание, молчит в режиме контрольной, без звуков.
- Сворачивается; выключается в настройках. Одна и та же фраза не повторяется подряд. Учитывает `prefers-reduced-motion`.
- Выбор фразы — логика без DOM (`js/companion.js`) с тестами.

## Не делать сейчас

- Звуки по умолчанию (только опцией в настройках, выключено).
- Новые задания и новые классы.

## Готово, когда
- Задачи фазы 5 закрыты отдельными коммитами; счётчики и значки переживают экспорт/импорт и обрезку истории.
- Все задачи фаз 1–3 закрыты отдельными коммитами, тесты и `validate` зелёные.
- Путь «первый вход → первый вопрос» на телефоне занимает не больше 3 нажатий.
- На странице темы кнопка старта видна без прокрутки на 390×844.
- Список тем математики на 390px помещается в 2–3 экрана при свёрнутых разделах.
- Нет регрессий в тёмной теме, крупном тексте и клавиатурной навигации.
- В конце — короткий отчёт: что сделано, что отложено и почему, какие решения принял сам.
