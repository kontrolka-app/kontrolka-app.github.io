# Олимпиадные задачи по математике, 4 класс — памятка для родителя

Тема в приложении: **«Олимпиадные задачи»** (`m4-olympiad`, раздел «Олимпиада»), 22 задачи: 5 лёгких (разминка), 10 средних, 7 трудных.

Памятка составлена по заданиям и решениям Всероссийской олимпиады школьников в Москве 2026/27 для 4 класса (пригласительный и школьный этапы). Задания использованы только для того, чтобы понять, какие **типы** задач встречаются. Все задачи в приложении придуманы заново; тексты, числа и сюжеты олимпиады не копировались. Классические головоломки (волк, коза и капуста; разлить 8 литров на 4 + 4) пересказаны своими словами.

## Как устроены этапы

- **Пригласительный этап** (весна): 8 задач, ответ обычно — число, выбор или расстановка; рисунков много.
- **Школьный этап** (осень): 8 задач, каждая в нескольких вариантах; засчитывается только верный ответ, без частичных баллов.

## Какие задачи встречаются

| Тип задачи | Что нужно уметь | Есть в приложении |
|---|---|---|
| Задуманное число, «решение с конца» | Делать обратные действия в обратном порядке | да (001) |
| Логика: кто сказал правду, кто на каком месте | Перебирать варианты, рассуждать «предположим, что…» | да (006, 007, 013, 020 — рыцари и лжецы, таблица) |
| Задачи на «части» и «переложил поровну» | Схема, отрезки | нет отдельной задачи (тот же приём «разница не меняется» — в 011) |
| Возраст («во сколько раз старше») | Разница в возрасте не меняется | да (011) |
| Промежутки: столбики, распилы, «между соседними» | Рисунок, «на один больше / меньше» | да (002, 003) |
| Подсчёт фигур (треугольники, квадраты) и разрезы | Считать по размерам, ничего не пропуская | да (015 — квадраты; разрезы торта и клетчатые фигуры — нет, нужны рисунки) |
| Числовые ребусы, расстановка знаков | Разряды, переносы, перебор | да (018, 019) |
| Магические суммы, расстановка чисел в кружки | Перебор, сумма всех чисел | нет (нужен рисунок) |
| Клетчатые фигуры, кубики, краска на поверхности | Пространственное мышление | нет (нужен рисунок) |
| Календарь и время | Дни недели повторяются через 7 | да (004, 021) |
| Взвешивания, переливания, переправы | План действий и доказательство «меньше нельзя» | да (008, 009, 016) |
| Чётность, принцип Дирихле («худший случай») | Рассуждение без длинных вычислений | да (005, 010, 022) |
| «Сколько способов», закономерности | Аккуратный перебор, поиск повторения | да (014, 017), движение с подвохом — 012 (улитка) |

В приложении нет задач с рисунками, поэтому разрезания, клетчатые фигуры и расстановки чисел на схемах лучше тренировать по бумажным заданиям прошлых лет.

## Как проверялись ответы

Каждая задача проверена программой полным перебором: ответ верный, и **другого ответа нет** (для задач «наименьшее число» — что меньшим числом не обойтись). Взрослый ещё не проверял тексты (`verified: false`), поэтому пройдите тему вместе с ребёнком и сверьте решения.

## Как заниматься

- Не торопите ребёнка: олимпиадную задачу нормально решать 10–15 минут.
- Просите объяснить вслух, **почему** других ответов нет, — это главное умение на олимпиаде.
- Подсказка в приложении даёт направление, а разбор после ответа — полное решение по шагам.
