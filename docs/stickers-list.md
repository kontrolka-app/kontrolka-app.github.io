# Альбом наклеек — список на согласование

Статус: **согласовано пользователем 2026-11-10** («Да, генерируй все»). Названия — в `js/stickers.js`, картинки — в `assets/stickers/` (сгенерированы в ChatGPT 2026-11-10: первые шесть животных по одной, остальные листами по четыре; разрезаны и сжаты до 384×384 WebP, весь альбом 1,4 МБ).

Что проверить: названия, нет ли лишних или неинтересных ребёнку, и 12 фраз на последней странице. Любую строку можно заменить.

## Общий стиль картинок

Одна и та же приписка к каждому запросу, чтобы все 48 выглядели как один набор:

> Наклейка для детского альбома: один персонаж по центру, плоский мультяшный рисунок, толстый тёмный контур, яркие чистые цвета, добрые глаза, белая кайма вокруг фигуры как у вырезанной наклейки, прозрачный фон, без текста, без букв и цифр, квадрат.

Без людей с узнаваемой внешностью, без чужих персонажей и логотипов.
