# Контролька — раздел «Смысловое чтение» (план)

Решение от 2026-10-29: делать **после редизайна** (после выкладки ветки `ux-redesign` в `main`), в отдельной ветке и отдельной выкладкой.

## Как работать

- Шаги по одному, один коммит на шаг. После каждого: `npm test`, `npm run validate`, проверка через `npm start` на ширине 390px и 1366px.
- Тексты и задания — только свои. Пособия из `uchebniki/` (Беденко «Смысловое чтение. 4 класс», Долгова «Чтение. Диагностика читательской компетентности», сборник «Читательская грамотность», тексты для проверки техники чтения) — образец типов вопросов, не источник текстов.
- Факты в научно-познавательных текстах сверять с учебником «Окружающий мир» из `uchebniki/`; не уверен — спросить.
- Новые задания с `"verified": false`.

## Что есть сейчас

- Тема `r4-vpr`: 3 своих текста, 22 вопроса. Текст целиком повторяется внутри каждого вопроса (`question`).
- Типов «выбери несколько» и «расставь по порядку» нет — задания ВПР № 5, 9, 10, 13 разбиты на отдельные вопросы (`docs/vpr-reading.md`).

## R1. Текст отдельно от вопросов

- В файле предмета — список `passages` (`id`, `title`, `author`?, абзацы текста); у вопроса — `passageId`.
- Экран вопроса: вопрос сверху, текст раскрывается кнопкой «Текст» и остаётся раскрытым при переходе к следующему вопросу того же текста.
- `validate`: `passageId` должен существовать; вопросы без `passageId` работают как раньше.
- Проверка: вопрос к тексту в 250 слов целиком виден на телефоне, текст можно перечитать.

## R2. Тип ответа `digits` (как на бланке ВПР)

- Порядок событий: ответ `3142`, порядок важен.
- Несколько верных: ответ `135`, порядок цифр не важен (поле `ordered: false`).
- Проверка только по данным вопроса (`checkAnswer`), тесты в `tests/`.

## R3. Тема «Смысловое чтение»

- 6–8 своих текстов разных видов (рассказ, научно-познавательный, сказка, инструкция), 120–250 слов.
- К каждому 5–7 вопросов: главная мысль, найти факт, значение слова по тексту, порядок событий, верно/неверно, заголовок, вид текста.

## R6. Русский язык: «Найди ошибки в тексте» (решение 2026-10-29, перед R4)

- Образец формата — фото `uchebniki/photo_2026-10-29_21-03-18.jpg` (короткие тексты про лес с нарочными ошибками). Тексты свои.
- Новый тип вопроса: текст из 5–8 предложений, в нём 3–6 слов с ошибками. Ребёнок нажимает на слова, которые считает неверными (повторное нажатие снимает отметку).
- Под текстом — список отмеченных слов, у каждого поле «Как правильно?». Вписать верное написание нужно сразу, затем «Проверить».
- Зачёт (решение 2026-10-29): задание верно, только если найдены все ошибки, нет лишних отметок и все исправления написаны верно. Подсчёт результатов и прогресса не меняется.
- После проверки — «Нашёл 4 из 5, исправил верно 3» и весь текст с правильным написанием: найденные, пропущенные и лишние отметки, неверные исправления выделены по-разному; у каждой ошибки — правило одной строкой.
- Данные: текст, у ошибочных слов — позиция, верное написание и правило. Проверка только по данным (`checkAnswer`): отмеченные слова = слова с ошибками, исправления сравниваются как в типе `text` (регистр не важен, ё = е).
- Верное написание сверять со словариком 4 класса и учебником Канакиной в `uchebniki/`. Тема в `russian-4.json`, `verified: false`.
