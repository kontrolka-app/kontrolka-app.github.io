# Контролька — голосовой навык Алисы

План для Claude Code. Отдельно от редизайна сайта (`docs/ux-tasks.md`): сайт не меняется.

## Идея

Ребёнок говорит «Алиса, запусти Контрольку», Алиса задаёт 10 вопросов голосом, проверяет ответы и называет счёт. Тренировка без экрана, лучше всего — устный счёт и вопросы «да/нет».

**Нейросеть не используется.** Алиса только распознаёт речь и произносит текст. Вопросы и правильные ответы — из наших `data/content/*.json`, проверка — нашей функцией `checkAnswer` из `js/quiz.js`, как на сайте.

```
Ребёнок → колонка / приложение Яндекс → Яндекс Диалоги
  → функция в Yandex Cloud (Node.js) → вопрос из JSON → текст ответа → Алиса произносит
```

## Что известно (проверено по документации, 2026-10-29)

- Ответ функции должен вернуться быстрее **4,5 секунды**, иначе Алиса скажет, что навык не отвечает.
- **Приватный навык** доступен только владельцу и тем, кому дали ссылку. Модерация у приватного — только имя для запуска и иконка, до 3 дней.
- Для функции нужен **платёжный аккаунт Yandex Cloud**. Точную стоимость при нашей нагрузке проверить на странице тарифов до старта (ожидаем около нуля).
- Официальный образец — навык «Попугай» на Node.js: <https://yandex.ru/dev/dialogs/alice/doc/ru/deploy-ycloud-function>.

## Что подходит для голоса (подсчёт по данным)

| Тип | Всего | Для голоса |
|---|---|---|
| `true-false` | 195 | да — ответ «да» / «нет» / «верно» / «неверно» |
| `number` | 269 | да — Алиса распознаёт числа |
| `text` | 157 | частично — короткие слова («Юпитер», «Нестор»). Не подходит всё про написание: знаки, буквы, «впиши» |
| `single-choice` | 468 | частично — только короткие варианты (≤ 3 варианта, ≤ 60 символов вместе: 90 штук), ответ «первый / второй / третий» или словом |

Русский язык для голоса почти не подходит (правописание). Хорошо — математика и окружающий мир.

## Ограничения

- Прогресс сайта (в браузере) колонка не видит. В навыке — только счёт за разговор.
- Знаки нужно переводить в речь: `×` → «умножить на», `:` → «разделить на», `−` → «минус», `…` в сравнениях — такие вопросы не брать.
- Длинные вопросы на слух тяжёлые — фильтр по длине.

## Решения — нужны до начала

1. **Какие вопросы задавать.** Сейчас у всех 1089 заданий `verified: false`.
   - а) Отдельный список «проверено для голоса» в `alice-skill/voice-set.json` (только `id` вопросов). Максим или взрослый проверяет тему — её `id` попадают в список. Данные заданий не трогаем. *(рекомендую; начать с одной темы математики)*
   - б) Брать все подходящие, как сайт, и в начале говорить «если думаешь, что ответ ошибочный, скажи „ошибка“».
2. **Имя для запуска.** «Контролька» или другое — проверить в консоли Диалогов, не занято ли.
3. **Где хранить код.** Папка `alice-skill/` в этом репозитории, ветка `alice-skill` от `main` (не в `ux-redesign`). Внимание: всё в `main` попадает на GitHub Pages — код функции станет виден, секретов в нём нет и быть не должно.
4. **Аккаунт Yandex Cloud и платёжный аккаунт** регистрирует взрослый сам — Claude это не делает.

## Шаги

Каждый шаг — отдельный коммит. После шага — что открыть и что увидеть.

### Шаг 1. Логика разговора без облака
- `alice-skill/` — модули без зависимостей:
  - `voice.js` — отбор вопросов для голоса и перевод знаков в речь;
  - `dialog.js` — разговор: приветствие → выбор предмета → 10 вопросов → счёт. Состояние разговора хранится в `session_state` ответа Алисы (у нас ничего не сохраняется);
  - разбор ответа: «да/нет», число словами и цифрами, «первый/второй», слово; проверка — через `checkAnswer`.
- Команды: «повтори», «подсказка», «не знаю», «хватит».
- Тесты `node:test` в `tests/alice-*.test.js`.
- `npm run alice` — разговор в терминале: пишешь ответы текстом, видишь, что ответила бы Алиса.
- **Проверка:** `npm test` зелёный; в `npm run alice` — пройти 10 вопросов математики и увидеть счёт.

### Шаг 2. Функция в Yandex Cloud
- `alice-skill/index.js` — обработчик по образцу «Попугая», вызывает `dialog.js`.
- Вопросы — из файлов, упакованных вместе с функцией (быстро, не зависит от сайта).
- Скрипт сборки архива для загрузки в Cloud Functions.
- **Проверка:** в консоли Yandex Cloud тестовый запрос → в ответе текст первого вопроса, время < 1 с.

### Шаг 3. Приватный навык
- В консоли Диалогов: новый навык, Backend — «Функция в Yandex Cloud», доступ — приватный.
- **Проверка:** «Алиса, запусти Контрольку» в приложении Яндекс → она задаёт вопрос, на ответ говорит «верно» / «неверно» и объяснение.

### Шаг 4. Модерация и ссылка
- Иконка (своя, линейная, в стиле сайта), имя для запуска → на модерацию.
- **Проверка:** статус «одобрен» в консоли; ссылка открывает навык на телефоне ребёнка.

## Не делать

- Нейросеть для вопросов, ответов или объяснений.
- Хранить что-либо о детях (имена, ответы, голос) у себя.
- Публичный навык в каталоге — только приватный.
- Связь с прогрессом на сайте.
