# «Учим стихи» — список стихов из учебника

Источник: «Литературное чтение. 4 класс», части 1 и 2 (`uchebniki/`, сканы). Страницы — по учебнику
(в PDF страница учебника N — это страница N + 1). Список составлен по оглавлениям и сверен со страницами.

Правило (решение 2026-10-29): текст встраиваем **только** у авторов, чьи стихи перешли в общественное
достояние (в России — 70 лет после смерти автора, т. е. умершие до 1956 года). Каждый текст перед вставкой
сверяется со сканом по странице. У остальных — только «автор — название — страница», текст ребёнок
вставляет сам (хранится только в его браузере).

## Решение 2026-10-29

Список согласован: группа А встроена (21 текст, перепечатан со сканов, сверено число строк), Б не берём, В — только
«автор — название — страница». У Глинки служебная пометка «Припев:» убрана из текста; знаки ударения (осени́,
Аллы́, было́) — как в учебнике.
