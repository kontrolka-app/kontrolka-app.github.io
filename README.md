# Контролька

Веб-приложение для подготовки к школьным контрольным: тренировки по темам, пробные контрольные, разбор ошибок с объяснениями, история прогресса и свои тесты, которыми можно делиться с классом.

Сейчас в приложении есть задания для **4 класса** (темы программы «Школа России»):

| Предмет | Тем | Заданий |
|---|---|---|
| Русский язык | 24 | 334 |
| Математика | 20 | 291 |
| Окружающий мир | 18 | 255 |
| Литературное чтение | 16 | 254 |

Сайт: https://kontrolka-app.github.io

В каждом предмете есть тема **«Подготовка к ВПР и диагностике МЦКО»** — свои задания в формате проверочных работ 4 класса (по официальным описаниям МЦКО 2025–2026), а по математике и русскому — **«Олимпиадные задачи»** (типы заданий ВсОШ, задачи свои). Обе группы тем вынесены на главную. Памятки для родителей: [docs/vpr-math.md](docs/vpr-math.md), [docs/vpr-russian.md](docs/vpr-russian.md), [docs/vpr-world.md](docs/vpr-world.md), [docs/vpr-reading.md](docs/vpr-reading.md), [docs/olympiad-math.md](docs/olympiad-math.md), [docs/olympiad-russian.md](docs/olympiad-russian.md).

Все задания и объяснения **оригинальные**. Они составлены по темам программы, но не копируют учебники и чужие банки заданий. Темы сверены с уроками «Библиотеки ЦОК», а правила, термины и факты — с учебниками «Школы России» (Моро, Канакина–Горецкий, Плешаков–Крючкова, Климанова, издания около 2023 г.). Подробности — в [docs/program-coverage.md](docs/program-coverage.md). Исключение — раздел «Учим стихи»: в нём тексты стихов из учебника, только авторов в общественном достоянии; современные стихи указаны без текста, его можно вставить самому ([docs/poems-list.md](docs/poems-list.md)). Тексты заданий писала нейросеть, поэтому у всех заданий стоит `"verified": false`: до проверки взрослым их стоит считать черновиком (см. «Проверка заданий»).

> Учебники, рабочие тетради, словарик класса, демоверсии МЦКО (`uchebniki/mcko`) и олимпиадные задания (`uchebniki/olimpiada`) для сверки лежат локально в `uchebniki/`. Эта папка исключена в `.gitignore` и **не должна публиковаться**: учебники защищены авторским правом. При загрузке через сайт GitHub (перетаскиванием) `.gitignore` не действует — не выбирайте эту папку.

## Запуск на компьютере

Нужен только [Node.js](https://nodejs.org) (LTS). Docker, установка библиотек и регистрация не нужны.

```bash
cd kontrolka
npm start
```

Откройте в браузере http://localhost:8080. Остановить сервер: `Ctrl+C`.

> Двойной щелчок по `index.html` **не сработает**: браузер не даёт странице, открытой как файл, загружать задания (`file://`). Нужен локальный сервер. Подойдёт `npm start`, VS Code Live Server или `python -m http.server 8080`.

## Публикация на GitHub Pages

Сайт собирается из ветки `main` репозитория [kontrolka-app/kontrolka-app.github.io](https://github.com/kontrolka-app/kontrolka-app.github.io), поэтому **push в `main` сразу публикует изменения** для всех, кто пользуется сайтом.

Сборка не нужна: все пути относительные, навигация работает через `#/…` в адресе. Файл `.nojekyll` отключает лишнюю обработку на стороне GitHub.

## Как пользоваться

Меню: **Главная**, **Темы**, **Прогресс**, **Я** (на телефоне снизу, на компьютере сверху).

- **Начать подготовку** — выбираешь предмет и тему. На странице темы есть правило с примерами, кнопка старта и настройка тренировки: количество вопросов, сложность, режим, порядок.
- **Режим «С подсказками»** — после каждого ответа видно, верно или нет, правильный ответ и объяснение. Есть подсказки.
- **Режим «Как на контрольной»** — без подсказок, результат и разбор в конце.
- **Пробная контрольная** — несколько тем одного предмета вперемешку.
- **Результат** — процент, количество верных, ошибок и пропусков, время. Для каждой ошибки показаны твой ответ, правильный ответ и объяснение, а если ребёнок выбрал неправильный вариант — почему он неверен. Для тем, где верно меньше 70%, показывается правило для повторения. Кнопка «Повторить ошибки» запускает тренировку только по ошибкам.
- **Смысловое чтение** — тексты отдельно от вопросов: текст раскрывается кнопкой и его можно перечитать.
- **Скорость чтения** — читаешь текст, нажимаешь «Стоп», видишь слова в минуту и норму для 4 класса, затем отвечаешь на вопросы на понимание. Это тренажёр для себя: проверить, что текст действительно прочитан, нельзя.
- **Найди ошибки в тексте** — по русскому: нажимаешь на слова с ошибками и пишешь, как правильно.
- **Учим стихи** — концы строк постепенно закрываются, можно учить по строфам и вставить своё стихотворение (оно хранится только в этом браузере). Без проверки и баллов.
- **Английский язык → Учим топики** — ребёнок загружает свой топик: фото или картинку (текст распознаётся прямо в браузере библиотекой Tesseract.js из `vendor/tesseract/`, фото никуда не отправляется), файл Word (.docx), .txt или вставляет текст. Сверяет распознанное с оригиналом, правит — и учит, как стихи: каждое предложение с новой строки, концы предложений закрываются по слову. Топики хранятся только в этом браузере. У предмета нет заданий: в `subjects.json` у него `"tool": "english"` (страница предмета с разделами) и пустой `files`.
- **Английский язык → Грамматика** — 21 тема: 13 по English World 3 (грамматика 12 юнитов из оглавления учебника и «Неправильные глаголы» из его словаря) и 8 по модулям Spotlight 4 (по грамматическому справочнику учебника), 248 оригинальных заданий (`data/content/english-4.json`). Обычные темы: прогресс, «Стоит повторить», цель дня и значки работают как в других предметах.
- **Английский язык → Слова по юнитам** — слова из словарей Word list двух учебников: English World 3 (основной, 398 слов, 12 юнитов, с. 126–128) и Spotlight 4 (378 слов: Starter, модули 1–8, сказка «Goldilocks» и «Ещё слова из учебника» — месяцы, числа, дни недели, страны, полезные фразы, Arthur & Rascal, культурные разделы; ч. 1 с. 90–93, ч. 2 с. 94–97; у слов, выделенных в учебнике цветом, пометка «узнавать»). Дней недели в словаре нет, числа дополнены до полного набора. Режимы: карточки, «выбери перевод», «напиши по-английски» и «диктант на слух» (голос браузера; первое слово — по кнопке) — ошибка — слово ещё раз в конце, счёт по первой попытке. В «напиши» и диктанте нет слов «узнавать» и целых фраз. Слова — в `data/english-words-4.json`; переводы составлены заново, `"verified": false`.
- **Английский язык → Неправильные глаголы** — 34 глагола из словарей обоих учебников (`data/english-verbs-4.json`): таблица с отметками «выучен», карточки, «выбери форму» (среди вариантов — ловушка вроде buyed) и «напиши форму». Круг — 10 глаголов, сначала невыученные; выучен — написан верно с первой попытки 2 раза подряд, ошибка сбрасывает серию.
- **Русский язык → Словарные слова по группам** — 16 групп (143 слова) из словарика класса для подготовки к словарному диктанту. В каждой группе 6 режимов: карточки, «вставь буквы» (слово пишется целиком), «выбери верное написание», «диктант на слух», «по алфавиту» (ё — после е) и «часть речи» (без «потому что», «как будто», «около», «столько»). Ошибка — слово ещё раз в конце, хранятся лучший и последний результат по группе и режиму. Слова и трудные места (в квадратных скобках: `к[о]р[и]дор`) — в `data/vocab-4.json`, таблица для сверки — `docs/vocab-words.md`. Ссылка на тренажёр — на странице предмета и в теме «Словарные слова 4 класса».
- **Нашёл ошибку?** — под вопросом: приложение готовит сообщение об ошибке в задании, его можно скопировать и отправить.
- **Прогресс** — все тренировки, изменение результата между попытками, темы с наибольшим числом ошибок.
- **Избранное** — звёздочка у темы.
- **Мои тесты** — редактор своих тестов и обмен ими (см. ниже). Открываются с главной и из раздела «Я».
- **Достижения** (в разделе «Я») — цель дня и серия дней, счётчики за всё время, 15 значков, «удивлялки», аватарка с аксессуарами и кнопка «Поделиться достижениями». Рейтинга класса и штрафов нет.
- **Компаньон** — персонаж в углу экрана подбадривает заготовленными фразами. Подсказок к ответам не даёт, на контрольной молчит, выбирается или выключается в разделе «Я».
- **Настройки** (в разделе «Я») — тема (как в системе, светлая, тёмная), размер текста, класс, имя, цель на день, сохранение копии данных в файл и восстановление, удаление прогресса.

## Свои тесты и обмен с классом

1. «Мои тесты» → «Создать тест». Типы вопросов: выбор варианта, верно/неверно, ввод слова, ввод числа. Можно добавить объяснение и подсказку.
2. «Поделиться» открывает на телефоне системное меню отправки (мессенджеры), на компьютере сохраняет файл `kontrolka-test-….json`.
3. Одноклассник: «Мои тесты» → «Открыть тест из файла». Файл проверяется: повреждённый или чужой файл не откроется.
4. После прохождения кнопка «Скопировать результат» копирует короткий текст с результатом, его можно отправить автору теста.

Важно: результаты отправляют сами ученики, проверить их подлинность нельзя. Для настоящих оценок нужна серверная версия с аккаунтами (её пока нет).

## Где хранятся данные

Всё хранится в `localStorage` **этого браузера на этом устройстве**:

- данные не синхронизируются между устройствами и браузерами;
- очистка данных браузера или приватный режим удалят историю;
- чтобы перенести прогресс, используйте «Я → Сохранить копию в файл», а на другом устройстве «Восстановить из файла».

Если сохранённые данные повреждены, приложение запустится с чистого листа и предупредит об этом. Испорченная копия сохраняется в браузере под ключом `kontrolka.data.corrupt-backup`. Приложение не собирает личные данные. Кроме загрузки своих файлов оно делает один вид сетевых запросов — к анонимному счётчику [GoatCounter](https://www.goatcounter.com) (`js/analytics.js`): только на опубликованном сайте, приложение передаёт только название открытого экрана и событие «тренировка завершена». По самому запросу сервис определяет браузер, систему и страну. Имя, ответы, результаты и id тем и тестов не отправляются. Адрес устройства (IP) передаётся сервису как при любом запросе в интернете; по описанию сервиса, адрес не хранится.

## Как добавить задания

Задания лежат в `data/content/<предмет>-<класс>.json`, список предметов — в `data/subjects.json`. Новый предмет или класс добавляется только через данные, код менять не нужно.

```json
{
  "id": "m4-speed-016",
  "grade": 4,
  "subjectId": "math",
  "topicId": "m4-speed-time-distance",
  "difficulty": "easy",
  "type": "number",
  "question": "Пешеход идёт 2 ч со скоростью 5 км/ч. Сколько километров он пройдёт?",
  "correctAnswer": 10,
  "unit": "км",
  "explanation": "Расстояние = скорость × время: 5 × 2 = 10 км.",
  "hint": "Вспомни формулу s = v × t.",
  "source": "Оригинальное задание проекта «Контролька»",
  "verified": false
}
```

Типы и поля ответа:

| `type` | `correctAnswer` | Дополнительно |
|---|---|---|
| `single-choice` | id варианта, например `"b"` | `options: [{ "id", "text", "feedback"? }]`, минимум 2; `feedback` объясняет, почему вариант неверный |
| `true-false` | `true` или `false` | — |
| `text` | строка | `acceptedAnswers` — другие верные записи; `caseSensitive: true` — различать регистр. Пробелы схлопываются, ё = е, знаки препинания **не** удаляются |
| `compare` | `"<"`, `"="` или `">"` | Задания «поставь знак сравнения»: вместо поля ввода — три крупные кнопки |
| `number` | число | `unit` — подпись рядом с полем; `tolerance` — допустимое отклонение (по умолчанию 0, т. е. точное совпадение). Принимается «12 500» и «3,5» |
| `digits` | строка из цифр, например `"2143"` | Ответ цифрами, как на бланке ВПР. `ordered: false` — порядок цифр не важен (цифры не должны повторяться) |
| `find-errors` | не нужен | `text` — текст, где слово с ошибкой записано как `{лису\|лесу\|Правило одной строкой.}`: написание с ошибкой, верное написание, правило |

У темы (`topics`) есть `id`, `subjectId`, `grade`, `title`, `section`, `description`, а также `theory` (абзацы правила) и `examples`.

Длинные тексты лежат в списке `passages` файла предмета (`id`, `title`, `paragraphs`, необязательно `author`, `intro`, `poem`), а вопрос ссылается на текст полем `passageId`. Стихи для «Учим стихи» — в `data/poems-4.json`.

После правки обязательно запустите проверку:

```bash
npm run validate
```

Примеры в правилах (`examples`, `theory`) не должны повторять выражения из вопросов — иначе правило подсказывает ответ. Проверка (её же запускает `npm test`):

```bash
npm run check-examples
```

## Проверка заданий

Тексты заданий составлены с помощью ИИ и проверены автоматически: формат, уникальность, а для математики — пересчёт ответов. **Взрослый или учитель их ещё не проверял.** Перед использованием в классе пройдите темы и сверьте ответы с учебником. Проверенным заданиям поставьте `"verified": true`. Если нашли ошибку, исправьте её в JSON и запустите `npm run validate`.

## Тесты

```bash
npm test
```

Автотесты (`node:test`, без сторонних библиотек) проверяют проверку ответов всех типов, нормализацию, выбор вопросов без повторов, подсчёт процентов, пропуски, защиту от повторной отправки, завершение сессии, сохранение и восстановление, повреждённые данные, экспорт и импорт, обмен тестами, значки, компаньона, стихи, скорость чтения, «Найди ошибки», а также то, что для каждого задания в базе правильный ответ действительно засчитывается.
